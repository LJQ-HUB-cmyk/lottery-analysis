## 关键设计决策（仍生效）

1. **Shell 薄入口 + Python Job 编排** — 脚本只做 cd/加锁/启动/日志，业务逻辑全在 `scripts/jobs/*.py`
2. **业务键去重（dedup_key）** — 靠期号而非文本 hash，同一期只推一次
3. **退出码统一** — 0=正常(含等待开奖)，2=业务异常，3=环境异常
4. **状态可追踪** — 每次任务落 `output/status/*.json`
5. **不做 LSTM/ML** — 彩票无时间依赖，统计方法更可靠

## 架构层次

```
Hermes cron → scripts/push/*.sh（薄入口）
  → scripts/jobs/*.py（业务编排）
    → scripts/hermes_push.py（推送内容生成+发送）
      → output/status/*.json（状态记录）
```
