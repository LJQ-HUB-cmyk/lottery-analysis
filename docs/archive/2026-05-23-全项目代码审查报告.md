### B1. `hermes_push.py` — `int("")` 崩溃（5 处）

**位置**：[hermes_push.py:202-203](scripts/hermes_push.py#L202) 及多处

**问题**：`int(item.get("Top1和值误差", 99))` 当 CSV 单元格为空字符串时，`.get()` 返回 `""`（key 存在但值为空），`int("")` 抛 `ValueError`。

**影响**：晚间复盘推送可能因 CSV 空字段崩溃。

**修复代码（可直接粘贴）**：

```python
def safe_int(value, default=0):
    """安全转 int：处理 None、空字符串、NaN、异常字符串。"""
    try:
        if value is None:
            return default
        s = str(value).strip()
        if not s or s.lower() in {"nan", "none", "null"}:
            return default
        return int(float(s))
    except (ValueError, TypeError):
        return default


def safe_float(value, default=0.0):
    try:
        if value is None:
            return default
        s = str(value).strip()
        if not s or s.lower() in {"nan", "none", "null"}:
            return default
        return float(s)
    except (ValueError, TypeError):
        return default
```

**替换规则**：全文件搜索 `int(.*get\(`，所有 CSV 字段读取改用 `safe_int`/`safe_float`。

```python
# 修改前
sum_err = int(item.get("Top1和值误差", 99))
span_err = int(item.get("Top1跨度误差", 99))

# 修改后
sum_err = safe_int(item.get("Top1和值误差"), 99)
span_err = safe_int(item.get("Top1跨度误差"), 99)
```

**优先级**：P0（第一批）

### B3. KL8 模块 — `int(x)` 对损坏 CSV 崩溃（4 个文件）

**位置**：[predictor.py:27](scripts/kl8/predictor.py#L27)、[reviewer.py:29](scripts/kl8/reviewer.py#L29)、[stats.py:24](scripts/kl8/stats.py#L24)、[check.py:42](scripts/kl8/check.py#L42)

**问题**：解析号码时 `int(x)` 无 try/except，遇到空格、空值、非数字直接崩溃。

**影响**：KL8 数据一旦有脏值，整个推送链路崩溃。

**修复方案**：新建 `scripts/kl8/common.py`，提供统一解析函数。

**修复代码（可直接粘贴）**：

```python
# scripts/kl8/common.py（新文件）

def parse_kl8_numbers(value, *, strict=False):
    """
    解析快乐8号码字段。
    支持：'01 02 03'、'01,02,03'、list[int]。
    strict=True 时遇到坏值直接 raise；默认跳过坏值。
    """
    if value is None:
        return []

    if isinstance(value, list):
        raw_parts = value
    else:
        text = str(value).replace(",", " ").replace("，", " ").strip()
        raw_parts = text.split()

    nums = []
    bad = []

    for x in raw_parts:
        try:
            n = int(str(x).strip())
            if 1 <= n <= 80:
                nums.append(n)
            else:
                bad.append(x)
        except (ValueError, TypeError):
            bad.append(x)

    if strict and bad:
        raise ValueError(f"快乐8号码存在非法值: {bad}")

    return nums
```

**使用方式**：

```python
# 修改前（predictor.py / reviewer.py / stats.py / check.py）
nums = [int(x) for x in row["号码"].split()]

# 修改后
from scripts.kl8.common import parse_kl8_numbers
nums = parse_kl8_numbers(row.get("号码"))
if not nums:
    continue  # 或在 check.py 中输出 warning
```

### B4. `kl8/predictor.py` — `next_issue()` 不处理年份翻转

**位置**：[predictor.py:36](scripts/kl8/predictor.py#L36)

**问题**：最新期号 `2025365` → 返回 `2025366` 而非 `2026001`。

**影响**：跨年时预测期号错误。

**修复方案**（需适配，GPT 建议不要硬编码 315）：

```python
def next_issue(latest_issue: str) -> str:
    """计算下一期号，处理年份翻转。
    期号格式: YYYYNNN（如 2025365 = 2025年第365期）"""
    if not latest_issue or len(latest_issue) != 7:
        return ""
    year = int(latest_issue[:4])
    seq = int(latest_issue[4:])

    # 判断该年最大期号（闰年366，平年365）
    import calendar
    max_seq = 366 if calendar.isleap(year) else 365

    if seq >= max_seq:
        return f"{year + 1}001"
    return f"{year}{seq + 1:03d}"
```

```python
import time

def is_fresh_file(path: Path, start_ts: float, max_age_seconds: int = 1800) -> bool:
    """检查文件是否在本轮运行中生成。"""
    if not path.exists():
        return False
```

### B11. `scoring_engine.py:188` — 形态评分上限截断使加分分支成死代码

**位置**：[scoring_engine.py:182-188](scripts/scoring_engine.py#L182)

**问题**：

```python
ratio = 1.0 + (theory_pct - actual_pct) / theory_pct
ratio = max(0.2, min(1.8, ratio))      # 允许 0.2~1.8
```

```python
# scripts/kl8/common.py（新文件）
def parse_kl8_numbers(value, *, strict=False):
    """解析快乐8号码字段。支持 '01 02 03'、'01,02,03'、list[int]。"""
    if value is None:
        return []

    if isinstance(value, list):
        raw_parts = value
    else:
        text = str(value).replace(",", " ").replace("，", " ").strip()
        raw_parts = text.split()

    nums = []
    bad = []

    for x in raw_parts:
        try:
            n = int(str(x).strip())
            if 1 <= n <= 80:
                nums.append(n)
            else:
                bad.append(x)
        except (ValueError, TypeError):
            bad.append(x)

    if strict and bad:
        raise ValueError(f"快乐8号码存在非法值: {bad}")

    return nums
```
